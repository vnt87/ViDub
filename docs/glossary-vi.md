# Thuật ngữ tiếng Việt

Tài liệu này thống nhất cách dịch các thuật ngữ trong ViDub. Khi dịch mới hoặc chỉnh sửa, hãy dùng đúng các thuật ngữ bên dưới.

| Tiếng Anh | Tiếng Trung (cũ) | Tiếng Việt |
| --- | --- | --- |
| workflow | 工作流 | quy trình |
| node | 节点 | nút |
| task | 任务 | tác vụ |
| subtitle | 字幕 | phụ đề |
| dubbing / voice-over | 配音 | lồng tiếng |
| voice clone | 声音克隆 | nhân bản giọng nói |
| voice reference | 参考音频 | âm thanh tham chiếu |
| ASR / transcription | 语音识别 | nhận dạng giọng nói |
| translation | 翻译 | dịch |
| source language | 原文语言 | ngôn ngữ nguồn |
| target language | 目标语言 | ngôn ngữ đích |
| forced alignment | 字幕对齐 | căn chỉnh cưỡng bức |
| export | 导出 | xuất |
| harness | 框架 (harness) | harness (giữ nguyên) |
| plugin | 插件 | plugin (giữ nguyên) |
| model | 模型 | mô hình |
| device / GPU | 设备 | thiết bị |
| setup / installation | 安装 / 环境配置 | cài đặt |
| download | 下载 | tải xuống |
| workspace | 工作台 | không gian làm việc |
| library | 任务库 | thư viện |
| review | 审核 | duyệt |
| preset | 预设 | cài sẵn |

## Quy tắc chung

- Giữ nguyên các tên riêng và tên sản phẩm: ViDub, YouDub, FFmpeg, Whisper, VoxCPM2, Qwen, Demucs, Electron, Windows, macOS, Linux.
- Giữ nguyên mã ngôn ngữ (`en`, `zh`, `ja`, `vi`) và các khóa cấu hình.
- Dùng tiếng Việt có dấu đầy đủ.
- Câu thông báo lỗi ngắn gọn, nêu rõ việc cần làm tiếp theo.
